# 🐍 Python Practice Hub

Учебная платформа для подготовки к ОГЭ/ЕГЭ по информатике — практика решения задач
на списки, строки и базовые структуры данных с **детерминированной проверкой кода**.

## Что внутри

Платформа построена вокруг одного принципа: «правильно/неправильно» определяется
**реальным исполнением кода**, а не сравнением с ответом или доверием модели.
Ученик пишет функцию `solve(data)`, код выполняется в изолированном песочнице и
сверяется с эталонным решением по курированным тестовым входам.

Состоит из трёх компонентов:

- **🌐 Веб-грейдер** (`webapp/`, FastAPI) — основная механика: ученик пишет код в
  браузере → проверка по тестам → история попыток → живая сессия с тьютором
  (общий экран кода, подсказки, аудиозвонок).
- **🤖 Telegram-бот** (`bot/`) — старая механика, запасной вариант: ученик
  присылает входные данные, бот считает и присылает правильный ответ. Код
  ученика не проверяется.
- **📚 Jupyter-ноутбуки** (`1_introduction/` … `5_strings/`) — методические
  материалы по темам, доступны и через сайт, и как отдельные `.ipynb`.

Банк заданий — **100 практических задач** на списки/строки (`bot/tasks.json` +
`bot/solvers.py`), единый для бота и веб-грейдера.

## Архитектура в двух словах

```
Браузер ученика/тьютора
    │  HTTPS (Caddy)
    ▼
Frankfurt (VPS): app (FastAPI) + coturn (STUN/TURN) + Caddy (TLS)
    │  WireGuard-тоннель
    ▼
Домашний роутер:
    executor  — изолированный запуск кода ученика (сеть запрещена)
    tutor-llm — прокси к DeepSeek API для ИИ-ассистента тьютора
```

Код ученика намеренно исполняется **не на публичной машине** — это отдельный
микросервис за WireGuard-тоннелем, в контейнере с read-only ФС, урезанными
capabilities и запрещённой исходящей сетью.

## Для ученика

1. Получите логин/пароль у тьютора (самостоятельной регистрации нет).
2. Зайдите на сайт (адрес выдаёт тьютор).
3. Выберите задание в левом списке, напишите `solve(data)` в редакторе.
4. Нажмите «Проверить» — код выполнится на тестовых входах, вы увидите, какие
   тесты пройдены и что вернуло ваше решение на каждом.
5. История попыток сохраняется между сессиями — можно вернуться и разобрать,
   где ошиблись.

Jupyter-ноутбуки с теорией по темам доступны в разделе «Материалы» на сайте.

## Технологии

- **Backend:** FastAPI, SQLAlchemy, MySQL (внешний, HOSTER), bcrypt для паролей
- **Frontend:** чистый HTML/CSS/JS, CodeMirror для редактора кода
- **Изоляция:** Docker (read-only rootfs, cap_drop ALL, iptables-запрет исходящей
  сети) поверх subprocess + timeout + RLIMIT
- **Realtime:** WebSocket (живой код ученика ↔ подсказки тьютора), WebRTC для
  аудиозвонка через собственный coturn (STUN/TURN)
- **Деплой:** `deploy-local.sh` — две машины (роутер + Frankfurt) одним скриптом
