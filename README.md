# 🐍 Python Practice Hub

Этот проект создан для обучения основам программирования на Python через **практику и обратную связь**.  
Содержит:
- ✨ **Jupyter-ноутбуки** с методическими материалами и примерами,
- 🤖 **Telegram-бота**, который принимает решения задач и проверяет ответы,
- 📚 **Коллекцию задач** по работе со списками, строками, числами и структурами данных.

---

## 🧑‍💻 Как работать с GitHub (для ученика)

1. Нажмите Fork в правом верхнем углу репозитория на GitHub.
2. Клонируйте свой форк:
```bash
git clone https://github.com/ВАШ-НИК/py-practice-hub.git
cd py-practice-hub
```
3. Создайте новую ветку:
```bash
git checkout -b feature/your-tasks
```
4. Внесите изменения, закомитьте и отправьте:
```bash
git add .
git commit -m "feat: add tasks {}"
git push origin feature/your-tasks
```
5. На GitHub нажмите Compare & pull request, чтобы отправить изменения наставнику.
