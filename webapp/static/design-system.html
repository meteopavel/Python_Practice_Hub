Дизайн-система

Спокойный, «серьёзный edtech». Холодные нейтрали + один синий акцент. Всё построено на CSS-переменных из styles.css. Тёмная тема включается автоматически через prefers-color-scheme — переключите тему ОС, чтобы проверить эту же страницу.

Палитра

Контраст проверен по WCAG 2.1 на светлой теме. Основной текст и акцент проходят AA (≥4.5:1), крупные элементы — AAA.
