Дизайн-система

Тёмная тема в стиле код-редактора. Тёмно-синий грунт, координатная сетка на рабочих зонах, моноширинные метки с акцентным маркером, один акцент teal. Глубина — через тональные слои поверхности, не тени. Острые углы. Всё построено на CSS-переменных из base.css.

Палитра

Тёмная тема. Контраст текста на фоне проверен по WCAG 2.1 — основной ~16:1, вторичный ~6:1 (оба ≥ AA). Цвет несёт функцию (pass/fail/working), не настроение.
